# 一、课程知识地图与环境基线

## 1. 知识地图

整门课可以压缩为一条完整的应用开发链路：

```
模型接入 → 提示词工程 → LangChain 组件 → RAG → 项目化 → 智能体扩展
```

**四个稳定抽象**（比记类名更重要）：

1. 模型接收什么、返回什么。
2. 链中前一个组件的输出，是否满足后一个组件的输入。
3. RAG 检索到的内容是否真正相关、可追溯。
4. 应用状态、知识库状态和会话状态分别由谁管理。

## 3. 模型接入

- **云端（通义千问 / DashScope）**：通过兼容 OpenAI 协议的 API 调用，`OpenAI` 客户端负责封装鉴权与流式事件处理。
- **本地（Ollama）**：适合离线学习，`ChatOllama` 负责生成，`OllamaEmbeddings` 负责向量化。**建库和查询必须使用同一个嵌入模型**。
- **密钥管理**：`.env` 管理密钥，`.gitignore` 至少加入 `.env`、`.venv/`、`__pycache__/`、`chroma_db/`。
