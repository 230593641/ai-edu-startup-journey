# 二、提示词工程六大技巧

一个可靠提示词的标准结构：

```
角色/目标 → 任务说明 → 输入数据及分隔符 → 执行步骤 → 输出格式/Schema → 边界条件与失败策略 → 必要示例
```

---

## 六大技巧

1. **清晰具体**：说明动作、对象、范围、标准。
2. **提供上下文**：补充业务背景和目标受众。
3. **使用分隔符**：用 XML 标签或成对标记隔离用户数据。
4. **指定步骤**：复杂任务拆成可检查的步骤。
5. **提供示例**：Few-shot 适合标签边界、特殊格式和业务术语。
6. **定义失败策略**：证据不足时明确回答"不知道"，不要猜测。

---

## Zero-shot vs Few-shot

| 类型 | 适用场景 | 关键原则 |
|------|----------|----------|
| Zero-shot | 简单通用任务 | 指令清晰即可 |
| Few-shot | 分类、抽取、格式约束 | 示例质量 > 数量 |

> 示例的质量比数量更重要。
