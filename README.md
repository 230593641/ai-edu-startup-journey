## 💡 项目核心定位

**不做大厂的重型平台，只做AI教育落地的"最后一公里施工队"。**

- 🎯 **切入点**：单兵极简工具（拍图批改），零门槛建立信任
- 🔒 **留存点**：校本智能体私有化部署，数据不出校园
- 🔓 **破冰点**：教师免费培训，用真实场景换痛点反馈

---

## 🎯 产品阶梯总览

```
引流层  →  口袋单兵利器（免费）     ← 老师自己用，建立信任
变现层  →  教研级学情雷达（1-3万/年） ← 卖给教研组长/教务处
增值层  →  特级教师经验分身（增值模块）← 解决新老教师断层
留存层  →  同源变式题生成（免费）     ← 提升使用粘性
```
